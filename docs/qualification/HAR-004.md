## Negative mutants (against the reference overlay)

Applied one mutation at a time directly to the committed reference overlay in the same throwaway
worktree, rerun via the suite CLI (`buildAndImport` rebuilds `@structile/agent-harness` as part
of the run — no separate `tsc` invocation needed), then reverted with `git checkout --` before
the next mutant.

**Mutant 1 — stale index consulted instead of ignored.** `graphify-policy.ts`,
`evaluateGraphifyIndex`: removed the `index.commitSha !== expected.commitSha` check, so an index
bound to a different commit is treated as current instead of being ignored.

```
{"testId":"HAR-004","status":"failed","exitCode":1,...}
measurements.error: "a stale index (commit) must be ignored\n\ntrue !== false\n"
```

Fails for the asserted reason: the suite's stale-commit case builds an index identical to the
current one except `commitSha` is replaced with `"0".repeat(40)` and asserts
`evaluateGraphifyIndex(...).usable === false`; with the commit check removed, the mutated index
is now reported `usable: true`, and the assertion fails on exactly that boolean.

**Mutant 2 — an inferred/unrecognized edge kind accepted as if resolved.** `graphify-policy.ts`,
`assertEdgeUsable`: removed the `edge.kind !== "RESOLVED"` gate entirely, so any edge object
carrying a non-empty `sourceRef` is accepted regardless of its `kind` — an edge the extractor
could only infer (or one of a kind the policy doesn't recognize at all) is no longer required to
be resolved to source before use.

```
{"testId":"HAR-004","status":"failed","exitCode":1,...}
measurements.error: "edge:unknown-kind was accepted but must be rejected"
```

Fails for the asserted reason: the suite's `assertDiscriminates` call pairs the `RESOLVED`
control edge against a poison edge of `kind: "GUESSED"` (carrying a non-empty `sourceRef`) and
expects only the poison to throw `GraphifyPolicyError`; with the kind gate removed, the poison
edge is accepted because its `sourceRef` alone now satisfies the (weakened) check, and the
discriminator reports the poisoned case was accepted rather than rejected. (The suite's other
inferred-edge fixtures — `kind: "INFERRED"` with no `sourceRef`, and with `sourceRef: ""` — still
fail the separate non-empty-`sourceRef` check even under this mutant, so this is the fixture that
actually discriminates the kind gate; it exercises the same "an edge the extractor could only
infer must not be trusted" class of assertion.)

**Mutant 3 — content-hash / source verification recording dropped.** `graphify-policy.ts`,
`evaluateGraphifyIndex`: removed the `contentHash` verifiability check (the
`typeof index.contentHash !== "string" || !CONTENT_HASH.test(...)` branch), so an index with an
absent, malformed, wrong-algorithm or empty content hash is no longer ignored — it is trusted
without any record of source verification.

```
{"testId":"HAR-004","status":"failed","exitCode":1,...}
measurements.error: "an index with a absent content hash must be ignored\n\ntrue !== false\n"
```

Fails for the asserted reason: the suite iterates `["absent","malformed","wrong-algorithm","empty"]`
content-hash variants and asserts each yields `usable: false`; with the verifiability check
removed, an index whose `contentHash` field is `undefined` (the "absent" case) is reported
`usable: true` instead, and the assertion fails on that boolean for the first variant tried.

Each mutant targets a distinct HAR-004 assertion class (stale-commit rejection, inferred/
unresolved-kind rejection, content-hash verification), and each was confirmed to fail
specifically on the mechanism exercising that class, not incidentally elsewhere.

+/**
+ * REFERENCE OVERLAY — not part of core `structile`. Written only to qualify the HAR-004
+ * protected suite (verifies requirement HAR-009) against a genuinely conformant candidate,
+ * since neither commit `653471d` nor current core `main` implements this surface. This file
+ * is the blueprint for the core micro-task that lands HAR-009 for real; see
+ * `docs/qualification/HAR-004.md` in `structile-conformance` for the appendix diff and status.
+ *
+ * Policy: a Graphify index is code-only local context, never evidence, and only usable when
+ * it provably matches the exact repository and commit under review with the running
+ * extractor; an edge the extractor could only infer must be resolved to source before a
+ * caller may rely on it.
+ */
+
+export const GRAPHIFY_EXTRACTOR_VERSION = "1.0.0";
+
+export class GraphifyPolicyError extends Error {
+  constructor(message: string) {
+    super(message);
+    this.name = "GraphifyPolicyError";
+  }
+}
+
+export interface GraphifyIndexExpectation {
+  repository: string;
+  commitSha: string;
+}
+
+export interface GraphifyIndexVerdict {
+  usable: boolean;
+  evidence: false;
+  reason?: string;
+}
+
+export interface GraphifyEdge {
+  from: string;
+  to: string;
+  kind: "RESOLVED" | "INFERRED" | string;
+  sourceRef?: string;
+}
+
+const CONTENT_HASH = /^sha256:[a-f0-9]{64}$/;
+
+function isRecord(value: unknown): value is Record<string, unknown> {
+  return typeof value === "object" && value !== null && !Array.isArray(value);
+}
+
+/** A code-only index may inform context only while it is provably current; otherwise it is ignored. */
+export function evaluateGraphifyIndex(index: unknown, expected: GraphifyIndexExpectation): GraphifyIndexVerdict {
+  if (!isRecord(index)) return { usable: false, evidence: false };
+  if (index.repository !== expected.repository) {
+    return { usable: false, evidence: false, reason: "index repository does not match the candidate repository" };
+  }
+  if (index.commitSha !== expected.commitSha) {
+    return { usable: false, evidence: false, reason: "index commit does not match the candidate commit" };
+  }
+  if (index.extractorVersion !== GRAPHIFY_EXTRACTOR_VERSION) {
+    return { usable: false, evidence: false, reason: "index extractor version does not match the running extractor" };
+  }
+  if (typeof index.contentHash !== "string" || !CONTENT_HASH.test(index.contentHash)) {
+    return { usable: false, evidence: false, reason: "index content hash is missing or not a verifiable sha256 digest" };
+  }
+  return { usable: true, evidence: false };
+}
+
+/** An INFERRED edge cannot authorise anything until it is resolved to a concrete source reference. */
+export function assertEdgeUsable(edge: unknown): void {
+  if (!isRecord(edge)) {
+    throw new GraphifyPolicyError("a graph edge must be an object");
+  }
+  if (edge.kind !== "RESOLVED") {
+    throw new GraphifyPolicyError(`an edge of kind ${String(edge.kind)} cannot be used until it is resolved to source`);
+  }
+  if (typeof edge.sourceRef !== "string" || edge.sourceRef.length === 0) {
+    throw new GraphifyPolicyError("a resolved edge must carry a non-empty sourceRef");
+  }
+}
